# Footpath Encroachment Mapping

A lightweight React + Vite prototype for a GVMC-style footpath encroachment reporting workflow.

## Features
- Home page with public and authority access
- Public login and complaint submission flow
- Encroachment description validation with a 50-character limit
- Before-image upload preview
- Authority dashboard to review and resolve complaints
- Local persistence using browser storage for a demo-ready experience

## Run locally
1. Install dependencies: npm install
2. Start the dev server: npm run dev
3. Build for production: npm run build
